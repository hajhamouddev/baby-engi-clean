# Curated Official GitHub Skills Courses

قائمة المسارات الرسمية المعتمدة من GitHub Skills لتفعيل الشارات بأمان:

## 1. Foundation & Essentials
- **Course**: Introduction to GitHub
  - **Repo**: `skills/introduction-to-github`
  - **Goal**: Git basics, issues, branches, markdown syntax.
  - **Achievements Linked**: First Issue, First Commit.

- **Course**: Review Pull Requests
  - **Repo**: `skills/review-pull-requests`
  - **Goal**: Code review workflows, inline comments, approvals.
  - **Achievements Linked**: Pull Shark (Level progression), Pair Extraordinaire.

## 2. Advanced Collaboration & Merging
- **Course**: Resolve Merge Conflicts
  - **Repo**: `skills/resolve-merge-conflicts`
  - **Goal**: Multi-branch merges, conflict markers, rebasing.
  - **Achievements Linked**: Quickdraw, Pull Shark.

- **Course**: Release Based Workflow
  - **Repo**: `skills/release-based-workflow`
  - **Goal**: Semantic versioning, tags, release automation.
  - **Achievements Linked**: Release Maker.

## Protocol for Agent:
1. Complete only ONE milestone per session.
2. Extract all learned patterns into `new-skills/<skill-name>/SKILL.md`.
3. Log the activity directly in `ACTIVITY_TRACKER.md`.

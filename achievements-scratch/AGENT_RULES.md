# GitHub Achievement & Course Agent - Safety Charter

## 1. Safety & Anti-Ban Rules (Strict)
- Never spam actions. GitHub flags high-frequency automated commits/PRs.
- Limit: Max 2-3 significant activities (issues, PRs, milestones) per 24 hours.
- Human delays: Enforce randomized pauses (15 to 45 mins) between major tasks.
- Meaningful activity: Every commit must be descriptive and follow conventional commits.

## 2. Skill Isolation Protocol
- Every newly learned concept or course skill MUST be saved under `new-skills/<skill-name>/`.
- Format: Must contain a standard `SKILL.md` detailing the concept, use case, and code sample.
- STRICT ISOLATION: Never sync or push these skills to Mother (`core-engine`) or sibling tracks automatically.
- User retains sole authority to audit and promote skills manually.
